This page has nothing to do with Bookly — it's deliberately a different "brand," different fonts, different colors — to prove the chat widget embeds cleanly on any site without clashing with the host page's design.

Look for the chat bubble in the bottom-right corner. It's running inside an isolated iframe, so none of this page's CSS can touch it (and it can't touch this page's CSS either).

How this demo works: the only Bookly-related thing on this whole page is one line before </body>:

<script src="https://YOUR-APP.onrender.com/embed.js" async></script>

Before opening this file, replace YOUR-APP below with your actual Render URL (or http://localhost:8000 if testing against a locally running backend).
